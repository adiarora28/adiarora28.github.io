An assistant that answers multi-step questions over a 175-page 10-K. It combines dense and keyword retrieval, reranks the results, and runs a tool-calling agent that checks its own retrieval before it answers.

Every stage was kept only if it improved recall, at the cost of latency (0.5 s to 3.1 s per query).

  • Fused OpenAI embeddings in FAISS with BM25 using Reciprocal Rank Fusion, then reranked with a cross-encoder.
  • The agent detects low-confidence retrieval, rephrases the query and retries. It uses a safe calculator for arithmetic instead of guessing.
  • Tested prompt injection with a poisoned chunk, wrapped retrieved text as untrusted context, and put a human approval step in front of the Slack action tool (MCP).
  • Kept a failure log that separates retrieval misses from generation errors. Answer accuracy on the internal eval was 88%.

Statistical Analysis and Machine Learning · solo · 2026

Predicts whether a US domestic flight arrives more than 15 minutes late (FAA/BTS definition).
